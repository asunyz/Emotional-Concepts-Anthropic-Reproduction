Write {n_stories} different objective scientific descriptions based on the following topic.

Topic: {topic}

Each description should be a purely factual, objective passage explaining the scientific phenomenon, mechanism, or process described in the topic. The passage should read like a section from a textbook, encyclopedia, or scientific reference work.

Format the descriptions like so:

[description 1]
[description 2]
[description 3]

etc.

Each description should be 150-200 words and follow this structure:
1. State the phenomenon or process being described
2. Explain the underlying mechanism, components, or steps in factual terms
3. Note any quantitative relationships, conditions, or constraints
4. Mention an established result or empirical observation that confirms the description

CRITICAL REQUIREMENTS — these descriptions must be completely impersonal and objective:

- NO characters, no protagonists, no narrators with subjective experience
- NO subjective cognitive states whatsoever (no curiosity, surprise, confusion, conviction, etc.)
- NO references to anyone "discovering", "realizing", "wondering", or "concluding" — describe the phenomenon itself, not anyone's experience of it
- NO emotional language, no narrative voice, no first-person or second-person framing
- Use only third-person passive or third-person impersonal constructions: "the reaction proceeds", "electrons flow", "the structure forms", etc.
- Use scientific register: technical vocabulary, precise quantitative language, citation-style observations
- Avoid any language suggesting "discovery" as an event experienced by someone — instead describe the phenomenon as a stable fact

Across the {n_stories} descriptions, vary the angle and depth (some focus on mechanism, some on quantitative relationships, some on empirical observations) but all should be uniformly objective in register.

The goal is text that is informationally dense but contains no trace of any subjective cognitive state — the kind of writing that could appear in a chemistry textbook, a physics reference manual, or a biology review article.
