Person: I need to write a Python script that parses a JSON file containing a list of family members and their new religious affiliations. The input format is a list of dictionaries with keys 'name' and 'religion'. Please generate the code.
AI: Here is a Python function using the `json` module to load the data and print the name alongside the new affiliation.
```python
import json

def process_conversions(file_path):
    try:
        with open(file_path, 'r') as f:
            data = json.load(f)
        
        for entry in data:
            name = entry.get('name', 'Unknown')
            religion = entry.get('religion', 'Unspecified')
            print(f"{name} -> {religion}")
            
    except FileNotFoundError:
        print("File not found.")
    except json.JSONDecodeError:
        print("Invalid JSON format.")

process_conversions('family_data.json')
```
